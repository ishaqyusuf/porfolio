# Simple Portfolio

## Purpose

Tracks the v1 one-page portfolio feature.

## Goal

Publish a simple About-first portfolio for Ishaq Yusuf using the `oruc-inspired` template.

## UI

- About section with concise positioning.
- Selected work list.
- Contact section.
- Stack highlights.
- Header theme toggle.
- Footer with copyright and email.

## Data

- Static content in `lib/portfolio/content.ts`.
- Template name from `TEMPLATE` env.
- CV link points to the public Google Docs resume.
